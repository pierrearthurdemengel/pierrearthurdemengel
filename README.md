# Pierre-Arthur Demengel

Symfony and Sylius developer based in Metz, France. I help e-commerce teams move from Sylius 1 to Sylius 2 before security support for Sylius 1.14 ends on 31 December 2026, and I build custom Sylius shops for companies whose current platform has become a constraint.

## Open source and research

- **[Sylius Upgrade Analyzer](https://github.com/pierrearthurdemengel/sylius-upgrade-analyzer)**: CLI that audits a Sylius 1.x project against the official upgrade notes, with 49 analyzers, 37 automatic corrections and effort estimates. Runs in Docker whatever the project's PHP version.
- **[Sylius 2 plugin readiness tracker](https://pierrearthurdemengel.github.io/sylius-2-plugin-readiness/)**: weekly status of every public Sylius plugin on Packagist.
- **[Sylius plugin ecosystem readiness for Sylius 2](https://doi.org/10.5281/zenodo.24224419)**: study of 802 plugins, with open data and scripts (Zenodo).
